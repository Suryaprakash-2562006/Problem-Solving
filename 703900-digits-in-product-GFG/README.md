# [Digits in Product](https://www.geeksforgeeks.org/problems/product-sum3012/1)
## Easy
Given two integers&nbsp;a&nbsp;and&nbsp;b. Write a program to find the number of digits in the product of these two integers.Example 1:
Input: a = 12, b = 4
Output:&nbsp;2&nbsp;
Explanation: 12*4 = 48
Hence its a 2 digit number.

Example 2:
Input: a = -24, b = 33
Output:&nbsp;3
Explanation: -24*33 = -792
Hence its a 3 digit number.

Your Task:&nbsp;&nbsp;You dont need to read input or print anything. Complete the function countDigits()&nbsp;which takes a and b&nbsp;as input parameter and returns the number of digits in the product of the two numbers.Expected Time Complexity: O(1)Expected Auxiliary Space: O(1)Constraints:-108&lt;= a,b&nbsp;&lt;=108
