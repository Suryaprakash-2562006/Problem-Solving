# [Anagram Strings](https://www.geeksforgeeks.org/problems/java-anagram-strings3549/1?page=1&category=Java&status=unsolved&sortBy=submissions)
## Easy
Given two strings S1 and S2 . Return "1" if both strings are anagrams otherwise return "0" .
Note:&nbsp;An anagram of a string is another string with exactly the same quantity of each character in it, in any order.Example 1:
Input: S1 = "cdbkdub" , S2 = "dsbkcsdn"
Output:&nbsp;0&nbsp;
Explanation: Length of S1 is not same
as length of S2.
Example 2:
Input: S1 = "geeks" , S2 = "skgee"
Output:&nbsp;1
Explanation: S1 has the same quantity&nbsp;
of each character in it as S2.
Your Task:&nbsp;&nbsp;You don't need to read input or print anything. Your task is to complete the function areAnagram()&nbsp;which takes S1 and S2 as input and returns "1" if both strings are anagrams otherwise returns "0".Expected Time Complexity: O(n)Expected Auxiliary Space: O(K) ,Where K= ContstantConstraints:1 &lt;= |S1|&nbsp;&lt;= 10001 &lt;= |S2|&nbsp;&lt;= 1000&nbsp;
